今年27届秋招地狱难度再创历史新高，这对于任何一个27届毕业生，乃至282930届小登都是一种极致的焦虑与迷茫。煮啵希望通过“路在何方”提供更广泛、更真实的视角，帮助处于迷茫期大学生认识自己、理解社会和不断探索，最终回答“路在何方”的终极问题。

## 产品组成

- **结构化知识库**：以目录树和章节顺序组织内容，像一本可以从头读到尾的探索手册；
- **免费开源AI Skill**：读取用户明确授权的本地知识库和个人探索记录，提供提问、解释、比较、检索、行动任务和复盘辅助；
- **个人探索空间**：记录用户情况、偏好、问题、路径比较、探索任务、行动结果和复盘；
- **真人主导的信任层**：由真实创建者提供内容筛选、方法论、持续维护和真人交付感；
- **反馈迭代闭环**：将用户反馈转化为知识库、评价规则和AI Skill的持续改进。

## 核心原则

1. 不替用户做人生决定，也不通过一次测评给出固定职业结论；
2. 明确区分事实、来源、用户信息、推断、建议和不确定性；
3. 优先给出可验证的低成本行动，而不是确定性过强的结论；
4. 知识库以目录树为骨架，支持连续阅读，辅助链接服务于主线；
5. AI Skill只读取用户明确授权的文件和目录；
6. 知识库和AI Skill免费提供，但使用范围和再发布条件以本仓库的许可证声明为准；
7. 用户反馈先记录和分类，再用于知识库、规则和Skill的迭代。
